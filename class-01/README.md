# Class 01

## Overview

Introductory lab for working with Claude Code. This module covers the basics of setting up a project, using core tools, and completing a first end-to-end task with the agent.

## Objectives

- Get comfortable with the Claude Code CLI workflow
- Practice reading, editing, and running code with agent assistance
- Understand how to structure prompts and review agent output

## Prerequisites

- Claude Code installed (see [BUILD.md](BUILD.md) for setup)
- A working shell (bash/zsh) and git installed
- Basic familiarity with the command line
